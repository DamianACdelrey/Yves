#### Capstone of Module 3

This project aims to predict, based on the available data, whether a customer has churned their subscription.

The project uses three different machine learning models to perform this classification task:

- Logistic Regression Classifier
- Random Forest Classifier
- Decision Tree Classifier

For each model, the project reports and compares their accuracy, precision, and recall, and discusses the implications of the results. Additional insights into model performance and potential improvements are also considered.
